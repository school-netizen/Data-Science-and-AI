# Task 4 — First Machine Learning Classifier

## Objective

Build and evaluate a supervised machine learning classification
model using Scikit-Learn.

## Dataset

Iris Dataset provided by Scikit-Learn.

## Model

Decision Tree Classifier.

## Key Concepts

- Train/test split
- Supervised learning
- Model training
- Prediction
- Accuracy
- Confusion matrix
- Precision
- Recall
- F1-score
- Feature importance

## Workflow

Data Loading → Data Preparation → Train/Test Split → Model Training
→ Prediction → Evaluation

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Conclusion

The project demonstrates the basic supervised machine learning
pipeline using a Decision Tree Classifier and evaluates its
performance using multiple classification metrics.
